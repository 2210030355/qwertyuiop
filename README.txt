VENNA REDDY BIRTHDAY WEBSITE - MOBILE EDITION

1. Upload index.html and venna.png to the ROOT of your GitHub repository.
2. Enable Settings -> Pages -> Deploy from branch -> main -> /(root).
3. Open https://YOUR-USERNAME.github.io/YOUR-REPO/ on a phone.

Tap screen: green gas cloud launches Venna upward with a silly synthesized fart sound.
Wings are decorative. Avoid TCS buildings.
Crash: Egg falls and Telugu text appears: OPEN CHYI RA EE GUUDU NI.
Tap egg twice: Egg cracks/hatches, photo rotates 100 full revolutions and flies upward.
After the 100 spins, a full-screen birthday poster appears.

Audio is generated by the browser, so no audio file is needed.
Mobile browsers require the first tap before sound may play.
